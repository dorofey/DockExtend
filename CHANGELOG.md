# Changelog

All notable changes to DockExtend are listed here.

## 0.1.0

Initial public version.

- Native macOS dock with multiple configurable docks and draggable launcher apps.
- Compact widgets for calendar, weather, music, notes, focus, running apps,
  workspace management, Herdr agents, and local LLM usage.
- Optional Slack message previews, Zed project previews, and Chrome tab previews.
- Per-dock layouts, display placement, and persisted settings.
